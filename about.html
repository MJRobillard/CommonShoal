About the project

A nonprofit, open source, community-run map, and nothing else.

Common Shoal turns boater tracks into a live shoal map for the Tred Avon & Choptank. Here's the organizational detail behind the game: who runs it, how it's funded, and where the project stands.

Context

Why a nonprofit

NOAA already runs a water-level monitor at this river's mouth and named the Choptank complex a federal Habitat Focus Area back in 2014. A live, crowdsourced shoal map is exactly the kind of dataset that effort can't generate on its own, but could absolutely put to use. Keeping this a nonprofit means the map serves that public interest, not a revenue target.
Open by design

How the commons stays a commons

  • Code is open source on GitHub, anyone can read it, fork it, or point out what's broken.
  • Sandbar data is released under an open geodata license, so no one, including us, can lock it up later.
  • No monetization: the pub tab and any prizes come from local sponsorship, not user data.
  • Every contributor's loops are attributed to them, on the map, permanently.
  • Decisions about the project happen in the open: issues, not backroom calls.
  • Built to hand off: if a local group wants to steward this long-term, it's built to be handed over.
